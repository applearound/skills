# 乐器合成配方与渲染质检

引擎内置四种乐器配方，均为公式合成，无采样依赖。本文档说明各配方的参数语义，以及为新乐器扩展配方的方法。

## 一、内置配方

### organ（管风琴，持续音类）

谐波叠加模型：每音符两层失谐正弦（±2.5 cent 加随机抖动），谐波幅度来自当前段落的音栓表。四档 STOPS 按每 8 小节逐级加亮（模拟逐步推音栓），低音声部叠加 16 倍副八度泛音列（f0/2 起的六个分音）。

参数位：gains 建议 0.75 到 0.95；混响用大厅参数（seconds 2.8、tau 0.95、wet 0.30）。

### dizi（笛，持续音类，民乐）

基频加二次三次谐波（幅度 1 / 0.14 / 0.05），揉弦颤音 5.2 Hz、延迟 0.18 秒渐入，领奏时颤音深度加倍（0.004 对 0.0025）。气声用一阶差分白噪 0.02 混入。起音 35 ms。

### zheng / qin（筝与琴，拨弦类，Karplus-Strong 物理模型）

KS 延迟线：初始噪声激励，每周期做一阶低通加衰减（衰减率由 T60 与频率决定）。双层失谐 ±4 cent 模拟双弦。区别在参数：

| 参数 | zheng（筝） | qin（琴，低音） |
|---|---|---|
| t60 | 1.8 s | 2.6 s |
| bright（低通保留系数） | 0.15（亮） | 0.05（暗） |
| 特性 | 快衰减、清脆 | 长余韵、沉厚 |

渲染层触键规则（拨弦类自动应用）：同音重拨时值缩至 0.82 分开，跳进 0.92 稍断，级进保持满值连奏。乐句末气口 0.92。

## 二、混响

合成脉冲响应：指数衰减噪声（长度 seconds、时间常数 tau），左右声道不同种子，前置 predelay。卷积用 rfft 快速实现。两类空间：

- 大厅/教堂：seconds 2.8、tau 0.95、predelay 25 ms、wet 0.30
- 小厅/排练室：seconds 2.0、tau 0.55、predelay 18 ms、wet 0.28

## 三、终止装饰钩子

- GLISSANDO：某声部终止首小节前半替换为快速下行刮奏（每音半个八分位），民乐体系筝声部用
- TRILL：长音替换为与本音交替的颤音后落回，调性体系终止导音用，aux 是装饰音的半音偏移

## 四、为新乐器扩展配方

配方只有两种物理形态，扩展时先归类：

1. 持续音类（organ / dizi 模式）：确定谐波幅度表、是否颤音（速率、深度、渐入时间）、起音时间、气声或噪声成分、包络形状。例如弦乐：谐波 1 到 6 缓降 + 5 Hz 浅颤音 + 40 ms 起音 + 弓噪
2. 拨弦或敲击类（KS 模式）：确定 t60、bright、失谐层数。例如扬琴：t60 1.2、bright 0.2；吉他：t60 2.2、bright 0.12

新配方写进模板的合成函数分发处（render 函数的 kind 分支），gain 参考同类配方起步，听输出调整。

## 五、MIDI 程序号（GM）

内置：organ 19、dizi 74（Flute 近似）、zheng 106（Koto 近似）、qin 45（Pizzicato Strings 近似）。GM 没有的民族乐器选音色最近的，MIDI 只是交换格式，听感以 WAV 为准。

## 六、渲染质检清单

WAV 产出后逐项检查：

```python
import wave, numpy as np
w = wave.open('out.wav', 'rb')
d = np.frombuffer(w.readframes(w.getnframes()), dtype=np.int16).astype(np.float64)/32768
L = d[0::2]
# 1. 无 NaN / Inf
# 2. 峰值 <= 0.85（引擎已归一化），削波样本数 = 0
# 3. 分段 RMS：声部递进时能量应上升（一、二、三声部段），结尾混响自然衰减
# 4. 时长 = N_POS * eighth + 混响尾
```

常见问题定位：峰值越界查 gains 配比；某声部几乎听不见查 gain 与乐器能量差（拨弦天然能量低于持续音，需 1.2 到 1.45 补偿）；整体发糊查混响 wet 与 tau；颗粒感查 KS 的 bright。
