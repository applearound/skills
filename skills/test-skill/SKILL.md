# Test Skill（临时测试技能）

这个技能存在的唯一目的：验证仓库结构与 SKILL.md 格式正确，能被 skills CLI 发现并安装、被代理加载。它被成功触发，就说明整条链路是通的。

## 触发场景

- 用户要求测试或验证 skill 安装是否成功。
- 安装完本仓库后，想确认技能能被代理正常发现和加载。

## 执行步骤

1. 向用户报告：测试技能加载成功，仓库安装链路正常。
2. 提醒用户：本技能是临时占位用的，链路验证完成后可以删除 `skills/test-skill` 目录，提交并推送即可。
